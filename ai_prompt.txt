# Prompt สำหรับพัฒนา Application ทะเบียนครุภัณฑ์และแผนผังอุปกรณ์แบบ 2D/3D

## คำสั่งหลักสำหรับ AI

คุณคือ Senior Full-stack Developer, Software Architect, Database Designer และ 3D Web Developer

ให้พัฒนา Web Application สำหรับจัดทำทะเบียนครุภัณฑ์คอมพิวเตอร์และอุปกรณ์เครือข่าย โดยผู้ใช้สามารถนำเข้าแผนผังของแต่ละอาคารและแต่ละชั้น เพิ่มอุปกรณ์ลงบนแผนผัง กำหนดตำแหน่งติดตั้ง ค้นหาอุปกรณ์ และแสดงผลได้ทั้งแบบ 2D และ 3D

ระบบต้องรองรับการติดตั้งแบบ On-premise ภายในโรงพยาบาลหรือองค์กร โดยไม่บังคับให้เชื่อมต่อบริการ Cloud ภายนอก

ให้พัฒนาระบบตาม Step ที่กำหนดด้านล่างทีละขั้น

ข้อกำหนดสำคัญ:

* ห้ามข้าม Step
* หลังจบแต่ละ Step ให้ตรวจสอบ Build, Lint และ Test
* ต้องแก้ไข Error ให้เสร็จก่อนดำเนินการ Step ถัดไป
* ห้ามสร้างเพียง Mockup หรือ Pseudocode
* ต้องสร้างไฟล์และโค้ดที่สามารถติดตั้งและรันได้จริง
* เมื่อจบแต่ละ Step ให้รายงานไฟล์ที่สร้างหรือแก้ไข
* ระบุสิ่งที่เสร็จแล้ว สิ่งที่ยังไม่เสร็จ และปัญหาที่พบอย่างตรงไปตรงมา
* ใช้ภาษาไทยสำหรับข้อความใน User Interface
* ใช้ภาษาอังกฤษสำหรับชื่อ Variable, Function, Class, API และ Database Field
* ใช้ TypeScript แบบ Strict
* หลีกเลี่ยงการใช้ `any`

# Step 9: การจัดเก็บพิกัดแบบ Normalized Coordinates

ห้ามจัดเก็บตำแหน่งเป็น Pixel แบบตายตัว

ใช้:

```typescript
positionX = pointerX / displayedImageWidth;
positionY = pointerY / displayedImageHeight;
```

ค่าต้องอยู่ระหว่าง 0 ถึง 1

เมื่อนำมาแสดง:

```typescript
displayX = positionX * currentImageWidth;
displayY = positionY * currentImageHeight;
```

สร้าง Utility Function:

```typescript
canvasToNormalizedPosition()
normalizedToCanvasPosition()
normalizedToWorldPosition()
worldToNormalizedPosition()
```

ข้อกำหนด:

* Resize แล้วตำแหน่ง Marker ต้องไม่เปลี่ยน
* Zoom แล้วตำแหน่ง Marker ต้องไม่เปลี่ยน
* Pan แล้วข้อมูลตำแหน่งต้องไม่เปลี่ยน
* Refresh แล้ว Marker ต้องอยู่จุดเดิม
* เปลี่ยน Monitor Resolution แล้ว Marker ต้องตรงตำแหน่งเดิม

* มุมซ้ายบน
* จุดกึ่งกลาง
* มุมขวาล่าง
* ค่า Boundary
* การแปลงไปและกลับ
* Floating Point Tolerance

raycaster.setFromCamera(pointer, camera);

* แก้ไขขนาดชั้นได้

* กำหนด Floor Rotation ได้

## Floor Plan

* Upload ได้
* Preview ได้
* Versioning ได้
* Activate ได้
* ภาพไม่ผิดสัดส่วน

## 2D Editor

* Zoom ได้
* Pan ได้
* เพิ่ม Marker ได้
* ย้าย Marker ได้
* ลบ Marker ได้
* Undo และ Redo ได้
* Resize แล้ว Marker ไม่คลาดเคลื่อน

## 3D Floor View

* โหลด Floor Texture ได้
* หมุนกล้องได้
* Zoom ได้
* Pan ได้
* หมุน Floor ได้
* Reset Camera ได้
* Top View ได้
* Perspective View ได้
* Marker ตรงกับ 2D
* Marker หมุนตาม Floor
* คลิก Marker ได้
* Search และ Focus ได้

## 3D Building View

* แสดงหลายชั้นได้
* แต่ละชั้นใช้ Floor Plan ของตนเอง
* เลือกชั้นได้
* ซ่อนชั้นได้
* Exploded View ได้
* Isolation Mode ได้
* Marker อยู่กับชั้นที่ถูกต้อง

* RBAC ทำงาน
* Viewer แก้ไขไม่ได้
* Network Data ถูกซ่อนตามสิทธิ์
* Audit Log ทำงาน
* Upload ปลอดภัย

## Performance

* รองรับ 500 Marker ต่อชั้น
* รองรับ 2,000 Marker ใน Building View
* ไม่มี Memory Leak เมื่อเปลี่ยนชั้นหลายครั้ง
* Texture ถูก Dispose
* UI ยังตอบสนองได้

## Testing

* Unit Test ผ่าน
* Integration Test ผ่าน
* E2E Test ผ่าน
* Build ผ่าน
* Lint ผ่าน
